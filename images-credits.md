# Image Credits — SHELIFT Website

All photographs currently used on the site are from **Unsplash** and are
licensed under the [Unsplash License](https://unsplash.com/license), which
permits free use including for commercial purposes (attribution appreciated).
These are **representative images** and do not depict SHELIFT programs, staff,
beneficiaries, or founder. Replace them with official SHELIFT field
photography when available by dropping files into `public/images/` under the
same filenames.

Reproduction:
```bash
npm run fetch:photos
```
